# speaker_notes

発表当日に Pixel Fold で表示する、スピーカーノート兼タイマーアプリ。
台本の正本は `assets/script.md`（ここに一本化。`docs/script.md` は廃止）。
その確定部分（スライド 01〜30）を表示する。

## 表示内容のルール

- `## 退避` セクション以降（旧台本・発音メモ）は表示しない
- `[VERIFY: ...]` / `[TODO ...]` の行は未確定として表示しない
- `**強調**` は太字 + アクセントカラーで表示
- `[→ step N]` の操作キューはチップとして表示

## 機能

- 全体タイマー（再生 / 一時停止 / リセット）
- 全スライドを縦に連続表示。下にスクロールすれば最後まで読める
- 上下ボタンで前後のスライドの先頭へスクロール
- 中央のページ番号タップで一覧からジャンプ
- 画面スリープ無効化（wakelock）

## 実行

```sh
flutter run   # Pixel Fold を接続して
```
